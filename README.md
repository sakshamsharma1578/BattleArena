# Battle Arena

A turn-based battle arena game developed using Python and Pygame. The project focuses on strategic combat mechanics, character abilities, animations, and AI-controlled opponents driven by heuristic evaluation and decision-tree logic.

## Features

- Turn-based combat system
- Multiple playable characters
- AI-controlled opponents
- Heuristic-based decision making
- Decision-tree-driven combat behavior
- Character animations
- Sound effects and visual assets
- Health and combat management system
- User interface for gameplay interactions

## Technology Stack

- Python
- Pygame

## Project Structure

- `Script/` – Core game logic and mechanics
- `assets/images/` – Game sprites and visual assets
- `assets/sounds/` – Sound effects and audio resources

## Learning Objectives

This project was developed to gain practical experience in:

- Game development using Pygame
- Object-oriented programming
- AI decision-making systems
- Turn-based game mechanics
- Animation and event handling
- User interface design for games

## AI System

The current AI implementation uses:

- Rule-based decision making
- Decision trees
- Heuristic evaluation functions

The AI does not currently implement machine learning or adaptive behavior learning.
